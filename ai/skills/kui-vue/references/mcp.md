# Kui Vue MCP

Start the server with `pnpm exec kui-vue-mcp`.

## Tools

- `search_components`: search names, tags, descriptions, props, and examples.
- `get_component_api`: retrieve the complete API for one component.
- `recommend_components`: map a UI requirement to suitable components.
- `validate_kui_usage`: detect unknown props in a Vue template.

## Resources and prompts

Component resources use `kui-vue://components/{Name}`. Reusable prompts cover forms, searchable tables, and modal editors.
